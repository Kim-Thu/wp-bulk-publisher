# WP Bulk Publisher

Desktop content operations tool for importing, normalizing, validating and publishing articles to multiple WordPress websites.

## Product goal

Turn heterogeneous content sources (CSV, Excel, DOCX and pasted HTML) into a controlled publishing pipeline:

**Import -> Map -> Normalize -> Validate -> Preview -> Process media/taxonomy/links -> Select site -> Publish -> Verify/Retry**

The project is being developed documentation-first from BA/BRD through UX, design system, SRS, architecture, implementation and QA.

## Documentation

See `docs/` for product and engineering specifications.

## MVP scope

- Import CSV, XLS/XLSX and DOCX
- Paste HTML copied from another website
- Normalize content into one article model
- Configurable cleaning/publishing presets
- Before/after preview and validation
- Multi-site WordPress profiles
- Categories and tags mapping/creation
- Image download, rename, upload and URL replacement
- Internal/external link transformation rules
- Draft/publish workflow
- Per-item publish result, error log and retry
